# 协作仓库迁移说明

日期：2026-11-16。

## 来源与新入口

从原BMC开发工作目录白名单提取源码，整理为独立redfish-workbench仓库：

| 原目录 | 新目录 | 处理 |
|---|---|---|
| BMC_Web_Manager | web | 保留后端、前端源码、锁文件、测试和启动器；不复制.env、data、.venv、node_modules和前端dist |
| BMC_CLI | cli | 保留入口、源码、测试、合成示例与CLI构建；不复制历史dist和交付包 |
| BMC_Node_Verifier | core | 仅迁入共享标准库核心、公开常量和回归测试；不迁旧桌面GUI或特定现场采集入口 |
| 旧打包脚本 | scripts/release.py | 移除固定日期、外部PDF和旧01–05目录依赖；从审核Git索引打包 |

原目录、原.env、现场资料、正式总表、采集证据和历史交付包保留原处，未移动、删除或回写。不自动同步两份源码；后续协作只修改新仓库。若旧环境有必须迁入的新修改，通过差异审查后手工合并。

## 有意调整

- 导入路径改为web/cli/core；未顺带重写协议、审批或升级规则。
- Web默认数据改为var/web；共享运行目录改为var/runs等；浏览器证据改为var/artifacts/browser。
- 后端配置源为新仓库根目录.env/环境变量，不读取父目录旧.env；没有复制任何现有凭据。
- 两项依赖具体现场工作簿的测试换成合成夹具；历史SN常量换成明确的合成标识。
- 桌面GUI不属于这次应用协作范围；原桌面功能仍在旧目录。
- 原文档中“当前版本”的历史说明保留在旧目录，新根README和docs作为协作说明。
- 公开常量资源保持原始字节，防止Git换行转换破坏其SHA256校验。

初始复制来源、哈希及后续调整后的文件哈希见reference/migration-map.json。该清单追溯源码迁移，不是现场硬件证据。源文件哈希可能因以后源目录继续修改而不再匹配，不能作为自动同步依据。

## 未进行的动作

源码迁移没有连接真实BMC、迁移现场台账/凭据或执行电源/升级。Git提交及远程发布按维护者后续明确要求分别进行，不因本地提交自动创建远程、推送或邀请成员。远程的权限/分支保护/CI需要团队实际配置。
